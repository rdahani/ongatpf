# Design System ATPF — v2 éditorial Sahel

## Direction
Photographie immersive + typographie éditoriale + crédibilité institutionnelle.

## Typographie
- Titres: **Fraunces** (serif chaleureuse, distinctive)
- Corps: **Figtree** (sans moderne, lisible)

## Palette
| Token | Hex | Usage |
|-------|-----|-------|
| Night | `#071A12` | Footer, overlays |
| Forest | `#0F3D2A` | Stats, structure |
| Leaf | `#1B6B45` | Primaire actions |
| Clay | `#B85A2F` | CTA partenaire |
| Gold | `#C9A227` | Accents numéros |
| Dust | `#E6D7B8` | Texte sur dark |
| Paper | `#FCFAF6` | Fond |

## Structure Accueil
1. Hero full-bleed (logo marque + 1 titre + 1 texte + CTAs)
2. Stats bandeau
3. Logos partenaires (preuve)
4. Story split photo/texte
5. Domaines en liste éditoriale (pas de cartes icônes IA)
6. Projet featured + grille
7. Impact / carte / approche / partenaires / actus / CTA

## Règles
- Header transparent sur hero, opaque au scroll
- Pas d’illustrations stock / emoji icons
- Contraste ≥ 4.5:1, cibles ≥ 44px
- Photos ATPF uniquement
